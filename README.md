# Student Management System – MySQL Project

## 📌 Project Overview
This project is based on a Student Management System using MySQL. It focuses on managing student records, course details, admissions, and payment information through SQL queries.

The main objective of this project is to practice SQL operations, joins, aggregate functions, filtering, and transaction management.

## 🎯 Project Tasks

The following SQL tasks were completed as part of this project:

1. **Insert Student and Course Records**
   - Insert new student details.
   - Add course records to the database.

2. **Update Student Details**
   - Modify existing student information using the UPDATE statement.

3. **Delete a Sample Record Safely**
   - Delete a sample record using the DELETE statement.
   - Practice safe deletion with appropriate conditions.

4. **Display Students with Their Enrolled Courses**
   - Use INNER JOIN to display student details along with their enrolled courses.

5. **Calculate Total Payments per Student**
   - Use JOIN and SUM() to calculate the total amount paid by each student.

6. **Identify Pending Fee Balances**
   - Calculate pending fees by subtracting total payments from the agreed course fee.

7. **Count Admissions Course-wise**
   - Use COUNT() and GROUP BY to find the number of admissions for each course.

8. **Display Payment History**
   - Retrieve payment records along with student details and payment dates.

9. **Filter Admissions by Date**
   - Use WHERE conditions to filter admission records based on specific dates.

10. **Practice Transactions and Rollback**
    - Use START TRANSACTION, COMMIT, and ROLLBACK to understand transaction management.
